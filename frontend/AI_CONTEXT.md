## 🎯 โปรเจกต์นี้คืออะไร?
โปรเจกต์นี้คือ "แชทบอทประเมินสุขภาพจิต" (Mental Health Assessment Chatbot) ทำงานแบบ Web Application 
เป้าหมายหลักคือให้ User เข้ามาพิมพ์พูดคุยกับบอท แล้วระบบหลังบ้านจะวิเคราะห์ระดับความเครียด/อารมณ์ ออกมาเป็นหมวดหมู่ (เช่น MILD, MODERATE, SEVERE)

## 🛠️ Tech Stack 
โปรเจกต์นี้แยกโฟลเดอร์ `frontend` และ `backend` ชัดเจน:
*   **Frontend (หน้าบ้าน):** Vue 3 (Composition API), Tailwind CSS, Vue Router, Pinia, Axios
*   **Backend (หลังบ้าน):** Node.js, Express, Prisma (ORM)
*   **Database:** PostgreSQL
*   **Security / Auth:** JWT (jsonwebtoken), bcryptjs (สำหรับเข้ารหัสผ่าน), CORS
*   **QA & Testing:** Jest, Supertest (สำหรับเทส API หลังบ้าน) และเตรียมทำ E2E ในอนาคต

## 📌 สถานะโปรเจกต์ปัจจุบัน 
*   **โครงสร้าง:** ขึ้นโปรเจกต์เสร็จแล้ว ทั้งหน้าบ้านและหลังบ้าน โค้ดหลักถูกรวม (Merge) อยู่ที่สาขา `develop`
*   **Backend:** ทำ API สำหรับ Register และ Login สำเร็จแล้ว (ผ่านการทดสอบ QA เรียบร้อย) กำลังเตรียมเซ็ตอัป Schema ใน Prisma เพื่อต่อกับ Database จริง
*   **Frontend:** กำลังปั้นหน้า UI (Home, Login, Register, Forgot Password) โครงสร้างโฟลเดอร์ Page และ Component มาแล้ว

## 🧠 กฎสำหรับ AI 
ถ้าผมส่งโค้ดมาให้ช่วยรีวิว หรือให้ช่วยเขียนฟีเจอร์ใหม่ ขอให้คุณยึดกฎต่อไปนี้:
1.  **สไตล์หน้าบ้าน:** เขียน Vue 3 แบบ `<script setup>` เสมอ และใช้ Tailwind CSS ในการจัดหน้าเป็นหลัก (หลีกเลี่ยงการเขียนไฟล์ .css แยกถ้าไม่จำเป็น)
2.  **เรื่อง Database:** ใช้ Prisma Syntax ในการคิวรีข้อมูลเสมอ
3.  **หมวก QA:** ผมมีหน้าที่ดูเรื่องการทดสอบระบบด้วย (Edge cases, Validation) ดังนั้นถ้าคุณเห็นโค้ดส่วนไหนที่เสี่ยงพัง หรือขาดการดักจับ Error ให้คุณเตือนผมทันที และเสนอ Test Case มาได้เลย
4.  **สไตล์การคุย:** ตอบกระชับ ตรงประเด็น เป็นภาษาโปรแกรมเมอร์คุยกัน ไม่อารัมภบทเยอะ โค้ดมา ลุยเลย!

## 🚨 ลอจิกสำคัญที่สุด (Business Logic)
*   **การจัดการเคสฉุกเฉิน (SEVERE):** ในระบบแชทบอท ถ้าบอทประเมินว่า User อยู่ในสภาวะวิกฤต (`Severity: SEVERE`) ข้อมูลที่ส่งกลับมาที่หน้าบ้านจะต้องทริกเกอร์ให้หน้า UI แสดง Modal สีแดง (Rose theme) ทันที พร้อมแสดงช่องทางติดต่อสายด่วน 1323 ห้ามข้ามลอจิกนี้เด็ดขาด
